# JS Removed Crosshair

[![Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/modrinth_vector.svg)](https://modrinth.com/project/lbBrGYD8)
[![GitHub](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/github_vector.svg)](https://github.com/HMLabs-Gaming/js-removed-crosshair)

This resource pack simply removes the crosshair from your Minecraft HUD — simple, clean, and effective.  
It’s compatible with Minecraft versions **1.20.2 and above**.
